## 一、Python 基础与面向对象

### 1. 常见的两种编程思维是什么？

常见的是面向过程编程和面向对象编程。面向过程把问题拆分成一系列执行步骤，关注“怎么做”；面向对象把问题抽象成对象及其行为，关注“谁来做”。

### 2. 什么是类和对象？

类是一类事物的抽象描述，对象是类的具体实例。类可以理解为图纸，对象可以理解为根据图纸生产出来的具体产品。

### 3. 什么是封装？有什么好处？

封装是把属性和方法放入类中，并通过对象或公共接口访问；对于不希望外部直接修改的数据，可以通过约定或属性访问器限制访问。封装可以隐藏实现细节、保护数据，并提高代码的模块化程度和可维护性。

### 4. 什么是继承？有什么好处？

继承是让子类自动拥有父类可继承的属性和方法，并可以在此基础上扩展或重写。它可以复用已有代码、减少重复，并形成清晰的层次结构。

### 5. 什么是多态？有什么好处？

多态是不同的类提供同名接口或方法，但执行时表现出不同的行为。调用方只依赖统一接口，不需要关注具体对象类型，因此代码更灵活、更容易扩展。

### 6. Python 中常见的魔法方法有哪些？

- `__init__`：创建对象后自动调用，通常用于初始化属性。
- `__str__`：使用 `print` 或 `str` 输出对象时调用，用于返回适合阅读的描述。
- `__del__`：对象被回收前可能调用，但不应依赖它执行关键的资源释放逻辑。

### 7. 闭包和装饰器需要满足什么条件？二者有什么关系？

闭包通常需要满足三个条件：存在嵌套函数，内部函数引用外部函数的局部变量，外部函数返回内部函数。装饰器常用闭包实现，在不修改原函数代码和调用方式的情况下，为函数增加额外功能，所以可以把“基于闭包实现并增加包装逻辑”的装饰器看作特殊的闭包应用。

### 8. 装饰器有什么作用？调用方式有哪几种？

装饰器可以在不修改原函数源码的前提下，为函数增加日志、计时、权限校验、缓存等功能。

常见调用方式有两种：手动调用，例如 `new_func = decorator(old_func)`；语法糖调用，在函数定义前使用 `@decorator`。实际开发中通常使用语法糖方式。

### 9. `global` 和 `nonlocal` 的作用是什么？

`global` 用于在函数内部声明并修改模块级全局变量；`nonlocal` 用于在嵌套函数中声明并修改外层函数作用域中的变量。二者都只影响变量查找和赋值作用域，不会自动解决并发下的数据竞争问题。

### 10. `match`、`search`、`findall` 有什么区别？

- `re.match`：从字符串开头开始匹配，开头不符合就返回 `None`。
- `re.search`：扫描整个字符串，找到第一个符合项后返回匹配对象，通常用 `group()` 取出文本。
- `re.findall`：扫描整个字符串，返回所有匹配结果组成的列表。

### 11. 正则表达式中的贪婪和非贪婪模式有什么区别？

默认量词是贪婪模式，会尽可能匹配更长的字符串；在量词后加 `?` 可以改为非贪婪模式，尽可能匹配更短的字符串。例如 `.*?` 通常用于获取两个边界之间的最短内容。

### 12. Python 的三元表达式怎么写？

Python 的写法是 `a if condition else b`。条件成立返回 `a`，否则返回 `b`。

## 二、网络编程与并发

### 1. IP 地址、端口号和协议分别有什么作用？

IP 地址用于定位网络中的主机或网络接口；端口号用于定位主机上的具体进程或服务；协议规定通信双方的数据格式、通信顺序和处理规则。

### 2. TCP 和 UDP 的核心区别是什么？

TCP 是面向连接的可靠字节流协议，具有确认、重传、排序和流量控制机制，可靠性高但开销较大。UDP 是无连接的数据报协议，不保证送达、顺序和去重，开销小、延迟低，适合实时性要求高且允许丢包的场景。

### 3. 简述 TCP 三次握手和四次挥手。

三次握手用于建立连接：客户端发送 `SYN`；服务端回复 `SYN + ACK`；客户端再回复 `ACK`，双方确认收发能力正常。

四次挥手用于断开连接：一方发送 `FIN`；另一方回复 `ACK`；另一方处理完剩余数据后发送 `FIN`；发起方回复 `ACK`。TCP 的连接关闭是双向独立的，因此通常需要四次报文。

### 4. Socket 有什么作用？

Socket 是操作系统提供的通信接口，可以让不同进程通过网络或本机协议栈交换数据。网络编程中通常用它完成连接、发送、接收和关闭等操作。

### 5. 客户端开发的五个基本步骤是什么？

1. 创建客户端 Socket。
2. 连接服务器的 IP 和端口。
3. 发送请求数据。
4. 接收响应数据。
5. 关闭 Socket。

### 6. 服务器开发的基本步骤是什么？

1. 创建服务器 Socket。
2. 绑定 IP 地址和端口号。
3. 调用 `listen` 开始监听。
4. 调用 `accept` 等待客户端连接。
5. 接收客户端数据。
6. 处理请求并发送响应。
7. 关闭连接和 Socket。

### 7. 并发和并行有什么区别？

并发表示多个任务在一段时间内交替推进，强调同时处理多个任务；并行表示多个任务在同一时刻真正同时执行，通常需要多核 CPU 或多个执行单元。并发不一定意味着并行。

### 8. 进程、线程和协程的定义与区别是什么？

- 进程是操作系统分配资源和进行隔离的基本单位，进程之间内存通常相互独立，开销较大，但稳定性好，适合利用多核处理 CPU 密集型任务。
- 线程是 CPU 调度的基本单位，同一进程内的线程共享大部分内存，创建和切换开销小，适合 I/O 密集型任务；CPython 中 CPU 密集型线程通常受 GIL 影响，难以充分利用多核。
- 协程是用户态的轻量级任务，由程序或事件循环主动切换，通常运行在单线程中，不能直接利用多核，但非常适合大量 I/O 等待场景。

### 9. 创建多进程任务的基本步骤是什么？

导入 `multiprocessing`，创建 `Process` 进程对象并传入目标函数，最后调用 `start()` 启动；需要等待子进程结束时调用 `join()`。在 Windows 下还要注意把启动逻辑放在 `if __name__ == "__main__":` 中。

## 三、数据库与 Redis

### 1. Python、PyMySQL 和 MySQL 的关系是什么？

MySQL 是关系型数据库，负责存储和管理数据；Python 是编程语言，负责编写业务逻辑；PyMySQL 是 Python 操作 MySQL 的驱动库，负责建立连接、执行 SQL 和读取结果。

### 2. SQL 语言有哪些主要分类？

- DDL：数据定义语言，用于创建、修改和删除库、表等结构。
- DML：数据操作语言，用于插入、修改和删除数据。
- DQL：数据查询语言，主要指 `SELECT`。
- DCL：数据控制语言，用于权限和安全控制。

### 3. `WHERE` 和 `HAVING` 的区别是什么？

`WHERE` 在分组前过滤原始行，不能直接使用聚合结果；`HAVING` 在 `GROUP BY` 之后过滤分组，适合根据 `COUNT`、`SUM` 等聚合结果筛选。

### 4. `ORDER BY`、`GROUP BY` 和 `LIMIT` 的作用是什么？

`ORDER BY` 对查询结果排序；`GROUP BY` 按指定字段分组，通常配合聚合函数使用；`LIMIT` 限制返回结果的行数或分页范围。

### 5. Redis 和 MySQL 有什么区别与关系？

MySQL 以表结构为主，数据主要持久化在磁盘中，适合保存完整、长期且需要事务和复杂查询的数据。Redis 以键值结构为主，数据主要在内存中，读写速度快，常用于缓存、计数、排行榜和消息等场景。

常见缓存流程是：应用先查 Redis；命中就直接返回；未命中时应用查询 MySQL，将结果写入 Redis，再返回结果。Redis 本身不会自动替应用查询 MySQL。

### 6. Redis 的五种常见数据类型及适用场景是什么？

- String：一个键对应一个值，适合验证码、计数器和简单缓存。
- Hash：一个键下包含多个字段，适合保存用户、商品等对象信息。
- List：有序、可重复，适合简单队列和消息列表。
- Set：无序、不重复，适合去重、共同好友等集合运算。
- Sorted Set：每个成员带有分数，适合排行榜和按分数排序的场景。

### 7. Redis 的持久化方式有哪些？

主要有 RDB 和 AOF。RDB 按策略定期生成内存快照，文件小、恢复快，但可能丢失最近一次快照之后的数据。AOF 以追加日志的方式记录写命令，数据恢复粒度更细，但文件通常更大、恢复可能更慢。生产环境可以根据数据可靠性和性能要求组合使用，并配置 AOF 刷盘策略。

## 四、Python 数据分析

### 1. NumPy、Pandas 和 Matplotlib 的作用与关系是什么？

NumPy 提供高效的多维数组和数值计算能力；Pandas 提供 `Series`、`DataFrame` 以及读表、筛选、排序、分组和缺失值处理等表格数据操作；Matplotlib 负责把数据绘制成图表。三者组合起来覆盖了 Python 数据分析中“计算、整理、可视化”的常见流程。

### 2. NumPy 数组为什么比 Python 列表计算更快？

NumPy 数组通常要求元素类型一致，数据在内存中连续存储，底层大量计算由 C 实现并支持向量化。Python 列表保存的是对象引用，元素可以是不同类型，存储和遍历开销更大。

### 3. Pandas 中 `Series` 和 `DataFrame` 有什么关系？

`Series` 是带索引的一维数据结构，可以理解为一列；`DataFrame` 是由多个 `Series` 按列组成的二维表格，每列可以有自己的数据类型。

### 4. Matplotlib 如何绘制图片？

先准备像素数组，可以自己创建形状为“高、宽、通道”的 NumPy 数组，也可以用 `plt.imread` 读取图片；再用 `plt.imshow` 显示数组，用 `plt.imsave` 保存图片，最后用 `plt.show` 展示图像。

### 5. NumPy 和 PyTorch 有什么区别？

NumPy 主要用于通用数值计算和数据处理，生态成熟、CPU 使用方便；PyTorch 除了提供张量运算，还提供自动微分、神经网络模块、GPU 加速和模型训练能力。深度学习项目中通常用 NumPy 做数据准备，用 PyTorch 完成训练和推理。

## 五、机器学习

### 1. AI 的三要素是什么？

数据、算法和算力。数据决定学习材料和上限，算法决定如何从数据中学习，算力决定训练和推理的效率及可处理的模型规模。

### 2. 数据集的常见组成要素有哪些？

样本、特征、标签、训练集和测试集。实际项目中通常还会划分验证集：训练集用于学习参数，验证集用于调参和选择模型，测试集用于最终评估泛化能力。

### 3. 机器学习有哪些主要类型？

- 有监督学习：数据有特征和标签，模型学习从特征预测标签。
- 无监督学习：只有特征没有标签，模型发现数据的结构或分布。
- 半监督学习：只有少量数据有标签，大量数据无标签。
- 强化学习：智能体与环境交互，根据行动获得的奖励学习策略，核心要素包括 Agent、环境、行动和奖励。

### 4. 机器学习的建模流程是什么？

数据获取与准备、数据预处理、特征工程、划分训练/验证/测试集、模型训练、模型预测、模型评估、调参与部署。实际流程通常是迭代进行的，而不是一次性线性完成。

### 5. MSE、RMSE 和 MAE 的含义是什么？

设预测值为 `y_hat`，真实值为 `y`，样本数为 `n`：

- MSE（均方误差）：`1/n * Σ(y_hat - y)^2`。对大误差更敏感。
- RMSE（均方根误差）：`sqrt(MSE)`，与目标变量单位一致。
- MAE（平均绝对误差）：`1/n * Σ|y_hat - y|`，对异常值相对更鲁棒。

### 6. 梯度下降算法有哪些分类？

- 批量梯度下降（Batch GD/FGD）：每次用全部训练数据计算梯度，方向稳定但单次计算开销大。
- 随机梯度下降（SGD）：每次用一个样本更新，速度快但波动较大。
- 小批量梯度下降（Mini-batch GD）：每次使用一小批样本，是深度学习中最常用的折中方案。
- SAG：使用历史梯度的平均值更新，能够减少随机梯度的波动。

### 7. 什么是欠拟合和过拟合？原因及解决方案是什么？

欠拟合表现为训练集和测试集效果都差，常见原因是模型过于简单、特征不足或训练不充分。可以增加特征、提高模型复杂度、训练更久或减弱正则化。

过拟合表现为训练集效果很好，但验证集或测试集效果差，常见原因是模型过于复杂、训练数据少、噪声多或训练过久。可以增加数据、数据增强、简化模型、正则化、Dropout、早停或交叉验证。

### 8. KNN 算法的实现步骤是什么？

先选择 `k` 值和距离度量；对新样本计算它与训练集中各样本的距离；选取距离最近的 `k` 个样本；分类任务采用多数投票，回归任务取邻居目标值的平均或加权平均。特征量纲差异较大时，应先进行标准化。

### 9. 分类算法常用哪些评估指标？

设 TP 为真正例、TN 为真反例、FP 为假正例、FN 为假反例：

- 准确率 Accuracy：`(TP + TN) / (TP + TN + FP + FN)`，适合类别相对均衡时使用。
- 精确率 Precision：`TP / (TP + FP)`，表示预测为正的样本中有多少是真的正例，误报代价高时更重要。
- 召回率 Recall：`TP / (TP + FN)`，表示真实正例中有多少被找出来，漏报代价高时更重要。
- F1：`2 * Precision * Recall / (Precision + Recall)`，用于综合平衡精确率和召回率，类别不均衡时常用。

### 10. 决策树是如何构建的？

从候选特征中选择最优切分特征，按照切分结果递归生成子节点，直到满足停止条件，再通过剪枝减少过拟合。分类树常使用信息增益、增益率或基尼指数选择切分，回归树常使用平方误差。

### 11. CART 决策树的原理是什么？

CART 强制使用二叉切分；每次选择能让节点不纯度下降最多的特征和切分点；对两个子节点递归分裂；叶节点输出类别或数值；最后通过预剪枝或后剪枝控制树的复杂度。分类 CART 常以基尼指数为依据。

### 12. TF-IDF 是什么？

TF 是词频，表示词在当前文档中的出现频率；IDF 是逆文档频率，表示词在整个文档集合中的稀有程度。TF-IDF 是二者的乘积，常见形式为：

`TF-IDF(t,d) = TF(t,d) * log(N / (DF(t) + 1))`

它计算快、可解释性强，但忽略词序和深层语义，通常作为关键词检索或传统文本分类的基线特征。

## 六、深度学习与 PyTorch

### 1. 机器学习和深度学习有什么区别？

传统机器学习通常需要人工设计特征，再由模型学习规律；深度学习通过多层神经网络自动学习特征。机器学习在数据较少时往往更容易训练和解释，深度学习通常需要更多数据和算力，在图像、语音、自然语言等复杂任务上表现更强，但解释性较弱。

### 2. PyTorch 在深度学习中主要用来做什么？

PyTorch 用于构建、训练和部署深度学习模型，主要能力包括张量计算、GPU 加速、自动微分、神经网络模块、优化器、数据加载和模型保存。

### 3. PyTorch 的自动微分是如何工作的？

对张量设置 `requires_grad=True` 后，PyTorch 会记录相关运算并构建动态计算图。调用 `backward()` 时，它会沿计算图进行反向传播，计算梯度并保存到对应张量的 `.grad` 中；优化器再使用这些梯度更新参数。

### 4. 什么是神经网络？搭建和训练步骤是什么？

神经网络是由多层神经元组成的参数化函数，通常包含输入层、若干隐藏层和输出层。搭建时先确定输入输出形式、网络层、激活函数和参数初始化方式；训练时依次进行前向传播、计算损失、反向传播和参数更新，循环多个批次和轮次，直到模型收敛或达到停止条件。

### 5. 如何在 PyTorch 中搭建最简单的神经网络？

继承 `torch.nn.Module`；在 `__init__` 中定义网络层；在 `forward` 中定义数据的前向计算过程；创建模型对象、损失函数和优化器；训练时按批次执行前向传播、损失计算、`backward()` 和 `optimizer.step()`。

### 6. 激活函数是什么？常见激活函数如何选择？

激活函数为网络引入非线性能力，否则多层线性变换仍然只能表示线性函数。

- ReLU：计算简单、收敛快，常用于隐藏层。
- Sigmoid：输出范围为 `0~1`，常用于二分类输出层或多标签任务，但深层网络中容易梯度消失。
- Tanh：输出范围为 `-1~1`，有时用于隐藏层或循环网络。
- Softmax：将多个类别的输出转换为概率分布，常用于单标签多分类输出层。
- 回归任务通常使用线性输出层。

### 7. 参数初始化有哪些方式？

常见方式有均匀分布、正态分布、全零/全一、固定值、Xavier 和 Kaiming 初始化。权重全部初始化为零会破坏神经元之间的对称性，通常不推荐；线性层和卷积层应根据激活函数选择合适的 Xavier 或 Kaiming 初始化，偏置一般可以初始化为零。

### 8. 损失函数是什么？如何按任务选择？

损失函数用于衡量模型预测结果与真实结果之间的差异，并为参数优化提供方向。回归任务常用 MSE、MAE 或 Smooth L1；二分类常用二元交叉熵；多分类常用交叉熵；具体选择还要考虑异常值、类别不平衡和输出层形式。

### 9. MAE、MSE 和 Smooth L1 有什么区别？

MAE 对误差取绝对值，对异常值较鲁棒，但零点处不可导或不光滑。MSE 对误差平方，大误差会产生更大的惩罚，但容易受异常值影响。Smooth L1 在误差较小时近似 L2，在误差较大时近似 L1，在平滑梯度和抑制异常值影响之间取得折中。

### 10. 什么是指数加权平均？有什么用？

指数加权平均让近期数据权重更大，较早数据权重按指数衰减。在优化算法中，它可以对历史梯度或梯度平方进行平滑，抑制更新波动，提高训练稳定性。

### 11. Momentum、RMSProp 和 Adam 的关系是什么？

Momentum 对梯度做指数加权平均，引入“惯性”以减少震荡；RMSProp 对梯度平方做指数加权平均，为不同参数自适应调整学习率；Adam 同时结合两者，既平滑更新方向，又自适应调整步长。

### 12. Adam 和 AdamW 的核心区别是什么？

传统 Adam 中权重衰减通常通过把 L2 正则项加入梯度来实现，正则化效果会受到自适应学习率的影响。AdamW 将权重衰减从梯度更新中解耦，先按 Adam 更新梯度，再单独衰减参数，通常能得到更稳定、清晰的正则化效果。

### 13. Dropout 和批归一化有什么作用？

Dropout 训练时随机关闭一部分神经元，减少神经元之间的过度依赖，主要用于缓解过拟合；推理时关闭 Dropout。批归一化对中间激活进行归一化，并学习缩放和平移参数，可以稳定训练、允许使用较大学习率，且有一定正则化效果。二者解决的问题不同，可以组合使用，但需要结合网络结构调节。

### 14. CNN 和 RNN 分别适合什么场景？

CNN 通过卷积提取局部空间特征，常用于图像、视频或局部模式明显的数据；RNN 通过循环隐藏状态建模序列前后关系，常用于文本、语音和时间序列。CNN 侧重局部空间结构，RNN 侧重时间或序列依赖。

### 15. PyTorch 中 CNN 和 RNN 常用哪些 API？

卷积层使用 `nn.Conv2d`，常用参数包括输入通道数、输出通道数、卷积核大小、步长和 `padding`；池化层使用 `nn.MaxPool2d` 或 `nn.AvgPool2d`；词嵌入使用 `nn.Embedding`；循环层可使用 `nn.RNN`、`nn.LSTM` 或 `nn.GRU`，常用参数包括输入维度、隐藏层维度和层数。

### 16. RNN、LSTM 和 GRU 有什么区别？

传统 RNN 使用当前输入和上一个隐藏状态计算当前隐藏状态，结构简单，但长序列中容易出现梯度消失或爆炸。

LSTM 在 RNN 基础上增加遗忘门、输入门、输出门和独立的细胞状态，能够更好地保留长期信息，但结构复杂、计算开销大。

GRU 将结构简化为更新门和重置门，去掉独立细胞状态，参数更少、计算更快，在很多任务中可以达到与 LSTM 接近的效果。

### 17. 什么是注意力机制？

注意力机制让模型动态关注输入中与当前任务更相关的部分。它使用 Query、Key、Value：先计算 Query 与各个 Key 的相关性得到权重，再对 Value 加权求和，得到聚焦于重要信息的表示。

### 18. 什么是 Seq2Seq？

Seq2Seq 由编码器和解码器组成。编码器读取输入序列并提取上下文表示，解码器根据上下文逐步生成输出序列，常用于机器翻译、摘要和问答等输入输出长度不固定的任务。

### 19. 简述 Transformer 框架。

Transformer 由《Attention Is All You Need》提出，核心是自注意力机制和前馈神经网络，并结合残差连接、层归一化和位置编码。原始结构包含编码器和解码器：编码器使用多头自注意力，解码器还包含带掩码的自注意力和对编码器输出的交叉注意力。它可以并行处理序列，长距离依赖建模能力强，是 BERT、GPT 等模型的重要基础。

### 20. 简述 PyTorch 动态量化。

动态量化通常预先将模型权重转换为低精度整数，激活值在推理过程中根据实际数据动态量化。它不需要重新训练或校准大量数据，适合对部分 CPU 推理模型进行压缩和加速，但支持的算子和加速效果取决于模型结构与硬件。

## 七、NLP 与文本分类

### 1. 文本处理有哪些基本方法？

常见方法包括分词、命名实体识别和词性标注。分词把连续文本切分为词语；命名实体识别人名、地名、机构名等实体；词性标注为词语标记名词、动词等语法类别。

### 2. 文本张量有哪些常见表示方法？

- One-hot：每个词用一个只有一个位置为 1 的高维稀疏向量表示，简单但维度高、没有语义相似性。
- Word2Vec：通过 CBOW 或 Skip-Gram 学习低维稠密词向量，能表达词语之间的语义和语法关系，但传统 Word2Vec 产生的是静态词向量，且对未登录词处理有限。
- Word Embedding：泛指把离散词映射为稠密向量的方法；`nn.Embedding` 是神经网络中的可学习嵌入层，训练时会随着任务更新参数。

### 3. FastText 是什么？有什么优点？

FastText 是 Facebook 开源的文本表示和分类工具，适合词向量训练和文本分类。它结构简单、训练和预测速度快，使用词的子词 `n-gram` 特征，能在一定程度上处理未登录词和拼写变化；同时支持层次 Softmax 和负采样等训练方式。

### 4. 使用 FastText 进行文本分类的步骤是什么？

准备带标签的数据，划分训练集和验证/测试集，训练模型，使用模型预测并评估，根据结果调节训练轮数、学习率、`wordNgrams`、损失函数等参数，最后保存并重新加载模型。

常用 API 包括 `fasttext.train_supervised()`、`model.predict()`、`model.test()`、`model.save_model()` 和 `fasttext.load_model()`。

## 八、大模型与 RAG

### 1. 大模型发展中的几个关键节点是什么？

2017 年 Transformer 架构提出，为后续大语言模型奠定了基础；2022 年 ChatGPT 让大语言模型进入大众视野；近几年国产模型持续发展，在推理能力、成本和应用落地方面扩大了影响。回答时间线题时，重点说明技术演进和影响即可，不必机械堆砌年份。

### 2. 什么是大模型幻觉？产生原因是什么？

大模型幻觉是指模型生成了表述流畅但事实错误、依据不足或不符合用户要求的内容。原因包括：模型本质上是在根据上下文预测后续词元；训练数据有时间范围，无法天然获得私有或实时信息；问题本身可能模糊或超出模型能力；模型被训练为尽量满足指令，可能在不确定时仍然给出完整回答。

### 3. 大模型幻觉有哪些类型？如何解决？

常见可分为事实性幻觉和忠实性幻觉。事实性幻觉是内容与客观事实不一致；忠实性幻觉是没有忠实遵守用户要求或给定上下文。

解决方案包括：在 Prompt 中明确资料边界和“不知道”条件；使用 RAG 引入可追溯的外部知识；通过微调固定特定任务的行为；使用工具调用获取实时数据；在程序侧做事实、格式和字段校验；对低置信度结果走兜底流程。

### 4. Prompt 设计有哪些常见原则？

清晰描述任务和输出要求；提供必要的参考文本；把复杂任务拆成多个简单步骤；给模型足够的上下文和处理空间；在需要时让模型调用外部工具或知识库；同时明确边界条件、异常情况和无法回答时的处理方式。

### 5. 什么是 CoT？适合哪些场景？

CoT（Chain of Thought）是思维链，让模型把复杂问题拆成多个中间步骤后再得到结果。它适合数学、逻辑、规划等多步推理任务；对简单事实问答通常没有必要，还可能增加输出长度和成本。生产系统应根据任务需要控制是否输出详细推理过程。

### 6. 什么是 ReAct？有什么用？

ReAct 将任务组织为“思考、行动、观察、再思考”的循环。模型先判断需要什么信息或工具，再执行搜索、数据库查询或代码调用，根据观察结果继续处理，适合需要外部信息和多步工具协作的任务。

### 7. 如何让模型稳定返回 JSON、表格或指定字段？

需要同时约束提示词和程序。Prompt 中明确输出格式、字段名、类型、必填项、枚举值和缺失值处理方式，并要求不要添加额外文本；生产环境再结合 Structured Output、Function Calling、JSON Schema 或 Pydantic 做结构约束。程序侧还要进行 JSON 解析、字段、类型和枚举校验，失败时可以要求模型重试或进入兜底流程。Prompt 负责说明目标，Schema 和代码负责验证结果。

### 8. 什么是 RAG？为什么使用 RAG？

RAG 是检索增强生成，核心思路是“先从知识库找证据，再让大模型基于证据回答”。它适合接入企业制度、产品手册、合同、FAQ 和工单等私有知识，可以缓解模型不知道企业知识、知识更新不及时和幻觉的问题。相比重新训练模型，更新文档和索引通常更快，也可以返回文档名、页码或 `chunk_id` 作为引用依据。

### 9. RAG 的完整检索流程是什么？

知识入库阶段：解析 PDF、DOCX、TXT 等文档，按规则或语义切片，使用 Embedding 模型将文本块转为向量并写入向量数据库，同时保留文档来源和 `chunk_id`。

在线问答阶段：接收用户问题，必要时进行 Query 改写，将问题向量化；使用关键词检索、语义检索或混合检索召回候选文本；用权重融合或 Rerank 模型重排；选择高相关片段拼入 Prompt；让大模型基于上下文生成答案，并返回引用来源或兜底结果。

### 10. 在 LangChain 中如何使用 RAG？

先加载文档，再使用文档分割器切块；通过 Embedding 模型将文档块向量化并写入向量数据库；创建 Retriever；收到问题后检索相关文档，将问题和文档上下文填入 Prompt，调用大模型生成答案。生产环境还要补充来源引用、权限过滤、异常处理和评估流程。

### 11. RAG 的文档分块策略有哪些？

- 固定长度分块：按字符或 Token 数切分，简单但可能破坏语义完整性。
- 递归分块：按段落、换行、句号、逗号等分隔符逐级切分，优先保留自然结构。
- 语义分块：根据相邻句子的语义相似度，在主题明显变化的位置切分。

普通文档可以采用语义分块并设置固定大小上限；代码或结构化文档更适合递归分块，并保留标题、表格和父子层级等结构信息。

### 12. Dify 和 RAGFlow 的分块方式有什么区别？

Dify 常见有通用分块和父子分块。通用分块按分隔符、长度和重叠长度切分；父子分块让子块负责检索，父块提供更完整的上下文。

RAGFlow 提供 General、Q&A、Manual、Table、Paper、Book、Laws 等面向不同文档类型的解析和分块方式，并会结合文档结构与语义单元调整切分，更适合复杂文档和长文本场景。实际效果仍取决于文档质量、参数和评估结果。

### 13. RAG 的检索策略有哪些？

关键词检索把查询分词后通过倒排索引查找匹配文档，精确匹配术语的能力强；语义检索把查询和文档转为向量，通过相似度寻找语义相关内容，能处理同义表达。工业场景通常采用关键词检索与语义检索的混合检索，再配合 Rerank 精排。

### 14. Embedding 模型和 Rerank 模型有什么区别？

Embedding 通常采用双编码器，将查询和文档分别编码为向量，可以提前计算文档向量，适合从海量数据中快速召回候选集。Rerank 通常采用交叉编码器，将查询和候选文档拼接后共同输入 Transformer，进行更细粒度的交互并输出相关性分数，但计算成本更高，所以只对少量候选结果精排。

### 15. 稠密向量和稀疏向量有什么区别？

稠密向量维度相对较低，通常每个位置都有数值，单个维度不一定有明确含义，整体表示语义；稀疏向量维度较高，只有少数位置非零，位置通常对应词或特征，数值表示词频或重要程度。Embedding 常生成稠密向量，TF-IDF/BM25 等关键词方法可看作稀疏表示思路。

### 16. 什么是 Rerank 模型？底层通常如何实现？

Rerank 是 RAG 的精排环节，负责对初步召回的文档片段重新打分。常见实现是交叉编码器：将用户问题和候选文档拼接后输入 Transformer，让二者进行词级注意力交互，输出相关性分数，再按分数排序。

### 17. 为什么需要在检索前改写 Query？常见策略有哪些？

用户问题可能口语化、包含指代、带有缩写、包含多个子问题或有无关修饰，而知识库文本通常更规范。直接检索会导致关键词匹配不足或语义偏移。

常见策略包括：根据多轮历史补全指代；拆分多个子问题分别检索；扩展缩写和同义词；去除噪声并重写为规范问题；让模型先生成假设答案，再用假设答案辅助检索（HyDE）。

### 18. RAG 召回内容太多时怎么办？

先用 Rerank 将最相关片段排在前面并限制 Top-K；通过 `chunk_id`、文档来源和相似内容做去重；调整切块大小和重叠长度；必要时对候选文档做压缩或摘要，最后控制进入 Prompt 的总 Token 数。

### 19. 没有召回相关知识时，如何让模型承认“不知道”？

在 Prompt 中明确要求只能基于给定资料回答，资料不足时必须返回“不知道”或指定兜底话术，不允许补写事实。系统侧可以设置 Rerank 分数或相似度阈值，所有候选低于阈值时直接返回兜底结果；要求答案附带来源，无法找到来源时不生成确定性结论；再持续收集无答案问题，补充知识库。

### 20. BM25 相比 TF-IDF 做了哪些改进？

TF-IDF 直接使用词频和逆文档频率，BM25 在此基础上加入词频饱和和文档长度归一化。词频饱和表示词出现次数越多，新增次数带来的收益越小，避免关键词堆砌；长度归一化会根据文档长度调整得分，避免长文档仅因包含更多词就占优势。`k1` 控制词频饱和速度，`b` 控制文档长度惩罚力度。

### 21. 如何评估 RAG 系统？

可以使用 RAGAS 等框架，从检索和生成两部分评估：上下文精确率/相关性衡量召回片段是否相关；上下文召回率衡量关键答案信息是否被召回；忠实度衡量答案是否由上下文支持；答案相关性衡量答案是否真正回答了问题。线上还应关注延迟、Token 成本、引用准确率、无答案识别率和用户反馈。

### 22. RAG 效果差时如何排查？

按链路逐段排查：知识库是否真的包含答案，原始文档是否过时；文档是否正确解析，表格和标题是否丢失；切块是否完整，向量是否成功写入；召回是否命中，混合检索权重和 Top-K 是否合理；Rerank 是否错误过滤；上下文是否真正进入 Prompt；模型是否遵守基于资料回答的约束。每一层都应保留日志和评估样本，定位到底是“找不到”还是“答不好”。

### 23. RAG、微调和 Prompt 分别适合什么场景？

Prompt 适合快速约束角色、流程和输出格式；RAG 适合知识经常变化、需要接入企业私有资料并返回依据的场景；微调适合固定输出风格、任务格式或领域行为，需要通过大量样本让模型形成稳定模式的场景。资料更新频繁时优先考虑 RAG，不能仅依靠微调记忆动态知识。

### 24. Coze 和 Dify 有什么区别？

Coze 更偏云端、低代码和快速搭建，适合快速验证想法和非技术用户；Dify 支持更多模型与组件，并可以本地部署，适合对数据私有化、流程编排和二次开发有要求的团队。具体选择还要结合部署方式、模型接入、插件生态、权限和成本，而不是只看上手难度。

## 九、项目面试题

### 1. 智慧问答系统的项目背景是什么？

传统教学中学生数量多、重复问题多，教师压力大，回答不及时且质量不稳定。智慧问答系统通过知识库和大模型实现全天候在线辅导，降低教师重复答疑压力，并提供更及时、个性化的学习支持。

### 2. 介绍一下投满分项目。

投满分本质上是一个新闻文本分类项目，业务背景来自新闻平台。平台每天收到大量第三方新闻，需要自动判断新闻类别，以便分析用户兴趣并进行更精准的内容或广告推荐。相比人工分类，机器分类速度更快，也能减少主观差异。

### 3. 投满分项目使用了哪些分类方案？如何选型？

项目尝试了随机森林 + TF-IDF、FastText、BERT 微调和外部 LLM API 四种方案。随机森林 + TF-IDF 开发快但效果有限；LLM API 泛化能力强但响应慢、成本高，适合做对比或基线；FastText 训练和推理快，适合强调开发效率和响应速度的场景；BERT 微调在准确率和响应速度之间更平衡，适合对效果要求较高的生产场景。

### 4. 投满分项目的数据集情况如何？

数据来自公司内部业务数据，包括历史新闻标题和运营人员的人工标注。数据约 20 万条，按 8:1:1 划分训练集、验证集和测试集；共 10 个类别，各类别比例相对均衡；标题平均长度约 25 个字。面试时应补充说明去重、清洗、标签质量和数据泄漏检查。

### 5. BERT 模型如何微调？

使用 `bert-base-chinese` 预训练模型，在模型顶部增加线性分类层，将新闻标题编码后输入 BERT，使用带标签的业务数据训练分类层及部分或全部 BERT 参数。训练完成后保存模型和分词器，推理时直接加载微调后的模型进行分类。

### 6. 如何评估投满分项目的模型好坏？

使用准确率、精确率、召回率和 F1 等指标。类别均衡时可以重点看准确率；类别不均衡时更关注宏平均或加权 F1；误判代价高时关注精确率；漏报代价高时关注召回率。最终还要结合推理延迟、吞吐量、模型大小和部署成本选择方案。

### 7. 为什么要进行模型压缩？常见方法有哪些？

模型压缩可以降低模型大小、内存占用和推理延迟，便于在 CPU、边缘设备或成本受限的服务中部署。常见方法有量化、剪枝、知识蒸馏、低秩分解和使用更小的模型结构。压缩后需要重新评估精度、召回率、延迟和资源占用，不能只看模型文件大小。

### 8. 手机价格预测项目如何设计？

这是一个监督学习的分类或回归项目，取决于标签是价格区间还是具体价格。先收集手机参数作为特征，清洗异常值和缺失值；使用 Pandas 读取并预处理数据，必要时对数值特征标准化；划分训练集、验证集和测试集并批量加载；定义继承 `torch.nn.Module` 的模型，选择损失函数和优化器；训练过程中进行前向传播、反向传播和参数更新，记录损失及评估指标；最后保存模型，在测试集上推理并验证泛化能力。

### 9. RAG 服务是如何部署的？

使用 FastAPI 提供服务接口，主要考虑三点：RAG 流程包含查询向量库和调用 LLM API 等 I/O 操作，适合使用 `async/await`；FastAPI 能自动生成 `/docs` 接口文档，便于调试和联调；依赖注入可以复用向量数据库客户端、Embedding 模型等重资源。

服务按 API 层、业务逻辑层和基础设施层拆分。`/chat` 接口先校验问题，再将问题向量化并从向量数据库召回 Top-K 片段，经过重排后拼接 Prompt，调用大模型生成答案，最后把答案和引用来源返回客户端。生产环境还需要增加鉴权、限流、日志、超时、缓存、监控和异常兜底。
